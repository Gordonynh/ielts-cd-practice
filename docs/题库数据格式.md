# 题库数据格式

格式版本：`ielts-cd-bank/1`

用于向 IELTS CD Practice 提供雅思题目。按这个格式整理的题目会直接转换成官方机考样式的作答界面，并支持自动判分、中文解析和段落翻译。

## 交付内容

把所有文件放进一个文件夹，压缩成 zip 发送：

```text
my-bank/
  sets/
    c18-test1.json      一套题一个文件
    c18-test2.json
  images/
    c18-test1-p2-diagram.png   题目用到的插图（没有可省略）
```

- 每个 JSON 文件是**一套题**，通常包含 3 篇阅读、共 40 题。只有单篇文章也可以，文件里只放 1 篇。
- 文件使用 UTF-8 编码，文件名与套题的 `id` 相同。
- 不要使用 HTML，所有内容都写在 JSON 字段里，排版由 App 生成。

## 套题文件

文件最外层是一个对象：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `format` | 必填 | 固定写 `"ielts-cd-bank/1"` |
| `id` | 必填 | 套题唯一标识，只用小写字母、数字和连字符，例如 `c18-test1`。所有文件之间不能重复。 |
| `title` | 必填 | 套题名称，例如 `Cambridge 18 Test 1` |
| `module` | 可选 | `"academic"`（学术类，默认）或 `"general"`（培训类） |
| `source` | 可选 | 来源说明 |
| `passages` | 必填 | 文章数组，1–3 篇，按 Part 1、2、3 的顺序排列 |

## 文章

`passages` 中的每一项是一篇文章：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `part` | 必填 | `1`、`2` 或 `3` |
| `title` | 必填 | 英文标题 |
| `titleZh` | 可选 | 中文标题 |
| `frequency` | 可选 | 出现频率：`high`、`medium`、`low` |
| `difficulty` | 可选 | 难度 1–5 |
| `text` | 必填 | 原文，见下方 |
| `groups` | 必填 | 题组数组，按题号从小到大排列，写法见“各题型写法” |
| `translation` | 可选 | 段落中文翻译 |
| `explanations` | 可选 | 每题中文解析 |

原文 `text` 的写法：

```json
{
  "heading": "The return of the urban beekeeper",
  "subheading": "Rooftop hives are spreading across the world's cities",
  "paragraphs": [
    { "label": "A", "text": "Ten years ago, keeping bees in a city was ..." },
    { "label": "B", "text": "Cities turn out to suit bees surprisingly well ..." }
  ]
}
```

- `subheading` 是标题下的副标题或导语，没有就省略。
- 原文中段落带字母（A、B、C…）时，必须填写 `label`；段落匹配题会用到。段落没有字母时省略 `label`。
- 一个自然段对应 `paragraphs` 里的一项。

## 通用规则

### 题号

使用试卷上的实际题号：Part 1 一般是 1–13，Part 2 是 14–26，Part 3 是 27–40。每篇文章内题号连续、不重复，每个题号只出现一次。“Questions 1–6”这样的题组标题由 App 自动生成，不用写。

### 填空位置 `{{题号}}`

填空题在文字中用 `{{题号}}` 标出答题框的位置，例如 `"Warmer temperatures extend the {{7}} season."`。每个标记都必须有答案，每个答案也必须有对应的标记。

### 答案

- 判断、选择、匹配题：写选项字母或固定值，如 `"C"`、`"iv"`、`"TRUE"`、`"NOT GIVEN"`。
- 填空题：照抄官方答案。有多种可接受写法时用数组，如 `["colour", "color"]`，也可以写成 `"4/four"`。
- 可以省略的词放在括号里，如 `"(vigorous) exercise"` 表示 `exercise` 和 `vigorous exercise` 都算对。
- 判分时会忽略大小写、首尾标点和多余空格，不需要为这些差异另写答案。

### 文字格式

- 不要写 HTML 标签。只支持两种格式：`**加粗**` 和 `*斜体*`。
- 摘要等较长文字需要分段时，用 `\n\n` 分隔。
- 逐字照抄原文：保留英式拼写、原有标点和斜体；去掉 PDF 中的页码、页眉页脚，以及行尾断词产生的连字符。
- 题目里不要加入任何答案提示。

### 题目说明与字数要求

`instruction` 建议照抄原题说明，例如 `"Do the following statements agree with the information given in Reading Passage 1?"`；不写时 App 会生成官方默认说明。填空题的字数要求写在 `wordLimit`，例如 `"NO MORE THAN TWO WORDS AND/OR A NUMBER"`。

## 题型一览

每个题组都有一个 `type` 字段，取下表中的值：

| type | 官方题型 | 说明 |
| --- | --- | --- |
| `true_false_not_given` | True / False / Not Given | 信息判断 |
| `yes_no_not_given` | Yes / No / Not Given | 观点判断 |
| `multiple_choice` | Multiple choice | 单选，每题一个答案 |
| `multiple_choice_multi` | Choose TWO / THREE letters | 多个题号共用一组选项，答案不分顺序 |
| `matching_headings` | Matching headings | 段落标题匹配，答题框显示在对应段落前 |
| `matching_information` | Matching information | 哪一段包含某信息，选项为段落字母 |
| `matching_features` | Matching features / Classification | 与人物、年代、类别等列表匹配 |
| `matching_sentence_endings` | Matching sentence endings | 句子前半与后半匹配 |
| `sentence_completion` | Sentence completion | 句子填空 |
| `summary_completion` | Summary completion | 摘要填空，词来自原文 |
| `summary_completion_options` | Summary completion (word list) | 摘要填空，从选项框中选 |
| `note_completion` | Note completion | 笔记填空 |
| `table_completion` | Table completion | 表格填空 |
| `flow_chart_completion` | Flow-chart completion | 流程图填空 |
| `diagram_label_completion` | Diagram label completion | 图表标注填空 |
| `short_answer` | Short-answer questions | 简答 |

> 原题如果不属于以上任何题型，请单独列出并附上原题截图，确认写法后再整理。

## 各题型写法

以下示例中的内容为原创示例文字；字段名和结构必须与示例一致。

### 判断题（`true_false_not_given` · `yes_no_not_given`）

答案只能是 `TRUE` / `FALSE` / `NOT GIVEN`，或 `YES` / `NO` / `NOT GIVEN`。

```json
{
  "type": "true_false_not_given",
  "instruction": "Do the following statements agree with the information given in Reading Passage 1?",
  "questions": [
    { "number": 4, "text": "Registering a hive in Paris is voluntary.", "answer": "FALSE" },
    { "number": 5, "text": "City honey contains fewer pesticides than rural honey.", "answer": "NOT GIVEN" }
  ]
}
```

### 单选题（`multiple_choice`）

```json
{
  "type": "multiple_choice",
  "questions": [
    {
      "number": 11,
      "text": "What is the writer's main purpose in Reading Passage 1?",
      "options": {
        "A": "to encourage readers to start keeping bees",
        "B": "to explain how honey is produced in cities",
        "C": "to present the benefits and drawbacks of urban beekeeping",
        "D": "to argue that honeybees should be removed from cities"
      },
      "answer": "C"
    }
  ]
}
```

### 多选题（`multiple_choice_multi`）

“Choose TWO letters” 这类题：`numbers` 列出共用这组选项的题号，`answers` 的个数与题号个数相同，顺序不限。

```json
{
  "type": "multiple_choice_multi",
  "numbers": [9, 10],
  "text": "Which TWO measures does the writer mention for protecting wild bees?",
  "options": {
    "A": "banning honeybees from public parks",
    "B": "limiting the number of hives in an area",
    "C": "introducing new species of wild bee",
    "D": "planting more flowering plants",
    "E": "reducing the price of city honey"
  },
  "answers": ["B", "D"]
}
```

### 段落标题匹配（`matching_headings`）

`paragraph` 必须是原文中存在的段落字母。原题给出例子（Example）时写在 `example`，没有就省略。

```json
{
  "type": "matching_headings",
  "instruction": "Choose the correct heading for paragraphs B–D from the list of headings below.",
  "headings": {
    "i": "Rules introduced to manage growth",
    "ii": "A hobby that went mainstream",
    "iii": "The financial rewards of honey production",
    "iv": "Advantages of the urban environment",
    "v": "Competition for scarce resources"
  },
  "example": { "paragraph": "A", "answer": "ii" },
  "questions": [
    { "number": 1, "paragraph": "B", "answer": "iv" },
    { "number": 2, "paragraph": "C", "answer": "v" },
    { "number": 3, "paragraph": "D", "answer": "i" }
  ]
}
```

### 段落信息匹配（`matching_information`）

选项自动取原文的段落字母。原题注明 “NB You may use any letter more than once” 时，写 `"allowReuse": true`。

```json
{
  "type": "matching_information",
  "instruction": "Which paragraph contains the following information?",
  "allowReuse": true,
  "questions": [
    { "number": 27, "text": "a reference to a study carried out in one city", "answer": "C" },
    { "number": 28, "text": "a suggestion for increasing the food supply of bees", "answer": "E" }
  ]
}
```

### 特征匹配 / 分类（`matching_features`）

与人物、年代、地点或类别的列表匹配；分类题（Classification）也用这个类型。`optionsTitle` 是选项框的标题，如 “List of Researchers”。

```json
{
  "type": "matching_features",
  "instruction": "Match each statement with the correct researcher, A–C.",
  "optionsTitle": "List of Researchers",
  "options": {
    "A": "Helen Ward",
    "B": "Tom Okafor",
    "C": "Ana Lindqvist"
  },
  "allowReuse": true,
  "questions": [
    { "number": 18, "text": "Bee numbers depend more on flowers than on hives.", "answer": "B" },
    { "number": 19, "text": "Training should be compulsory for new beekeepers.", "answer": "A" }
  ]
}
```

### 句子结尾匹配（`matching_sentence_endings`）

```json
{
  "type": "matching_sentence_endings",
  "instruction": "Complete each sentence with the correct ending, A–E, below.",
  "options": {
    "A": "because they compete with wild bees.",
    "B": "because cities are warmer than the countryside.",
    "C": "to limit the density of hives.",
    "D": "to attract more customers.",
    "E": "to protect rare plants."
  },
  "questions": [
    { "number": 20, "text": "Bees can forage for longer in cities", "answer": "B" },
    { "number": 21, "text": "Some districts of Paris have introduced rules", "answer": "C" }
  ]
}
```

### 句子填空（`sentence_completion`）

每题的 `text` 中有且只有一个 `{{题号}}`，与该题的 `number` 一致。

```json
{
  "type": "sentence_completion",
  "instruction": "Complete the sentences below.",
  "wordLimit": "ONE WORD ONLY",
  "questions": [
    { "number": 7, "text": "Warmer temperatures in cities extend the {{7}} season for bees.", "answer": "foraging" },
    { "number": 8, "text": "Experts recommend creating bee {{8}} to connect green spaces.", "answer": ["corridors", "corridor"] }
  ]
}
```

### 摘要填空，原文取词（`summary_completion`）

整段摘要写在 `text`，答案写在 `answers`，键为题号。

```json
{
  "type": "summary_completion",
  "instruction": "Complete the summary below.",
  "wordLimit": "NO MORE THAN TWO WORDS",
  "title": "Why cities suit bees",
  "text": "Parks and gardens offer a wide variety of {{22}}, and far fewer {{23}} are used than on farmland.",
  "answers": {
    "22": ["flowering plants", "plants"],
    "23": "pesticides"
  }
}
```

### 摘要填空，选项框（`summary_completion_options`）

```json
{
  "type": "summary_completion_options",
  "instruction": "Complete the summary using the list of words, A–F, below.",
  "title": "A growing debate",
  "text": "Ecologists warn that too many hives may reduce the {{12}} available to wild bees. Cities such as Paris have responded with stricter {{13}}.",
  "options": {
    "A": "food",
    "B": "regulation",
    "C": "funding",
    "D": "space",
    "E": "awareness",
    "F": "competition"
  },
  "allowReuse": false,
  "answers": { "12": "A", "13": "B" }
}
```

### 笔记填空（`note_completion`）

`lines` 按显示顺序排列：`"heading": true` 表示小标题，`level` 表示缩进层级（0 为顶格，1、2 依次缩进）。

每一行只写这一行自己的内容：不要重复上一行的文字，不要把多行合并成一行，也不要用 `"undefined"` 等文字占位（没有的内容直接省略）。

```json
{
  "type": "note_completion",
  "instruction": "Complete the notes below.",
  "wordLimit": "ONE WORD AND/OR A NUMBER",
  "title": "Urban beekeeping in Paris",
  "lines": [
    { "text": "Rules", "heading": true },
    { "text": "every hive must be {{24}}", "level": 1 },
    { "text": "some districts limit hive numbers", "level": 1 },
    { "text": "New beekeepers", "heading": true },
    { "text": "encouraged to take a {{25}} course", "level": 1 }
  ],
  "answers": { "24": "registered", "25": "training" }
}
```

### 表格填空（`table_completion`）

`columns` 是表头；`rows` 中每行的格子数与表头相同，空格子写 `""`。

```json
{
  "type": "table_completion",
  "instruction": "Complete the table below.",
  "wordLimit": "NO MORE THAN TWO WORDS",
  "title": "Early types of bicycle",
  "columns": ["Name", "Date", "Main feature"],
  "rows": [
    ["Draisine", "1817", "had no {{14}}"],
    ["Penny-farthing", "1870s", "very large {{15}}"],
    ["{{16}}", "1885", "chain-driven rear wheel"]
  ],
  "answers": {
    "14": "pedals",
    "15": "front wheel",
    "16": ["Safety bicycle", "Safety"]
  }
}
```

### 流程图填空（`flow_chart_completion`）

```json
{
  "type": "flow_chart_completion",
  "instruction": "Complete the flow-chart below.",
  "wordLimit": "ONE WORD ONLY",
  "title": "How recycled paper is made",
  "steps": [
    "Waste paper is mixed with water to form a {{30}}.",
    "Ink is removed using air bubbles.",
    "The fibres are pressed and {{31}} on heated rollers."
  ],
  "answers": { "30": "pulp", "31": "dried" }
}
```

### 图表标注（`diagram_label_completion`）

图片上需要保留原题标注的题号；`labels` 按题号列出每个标注的文字。

```json
{
  "type": "diagram_label_completion",
  "instruction": "Label the diagram below.",
  "wordLimit": "NO MORE THAN TWO WORDS",
  "title": "A rooftop hive",
  "image": "images/sample-test1-p1-hive.png",
  "labels": [
    { "number": 32, "text": "{{32}} where honey is stored" },
    { "number": 33, "text": "entrance protected by a {{33}}" }
  ],
  "answers": { "32": "upper box", "33": "mesh screen" }
}
```

### 简答题（`short_answer`）

```json
{
  "type": "short_answer",
  "instruction": "Answer the questions below.",
  "wordLimit": "NO MORE THAN THREE WORDS AND/OR A NUMBER",
  "questions": [
    { "number": 34, "text": "In which year was the London study carried out?", "answer": "2019" },
    { "number": 35, "text": "By how much can the foraging season be lengthened?", "answer": ["three weeks", "3 weeks"] }
  ]
}
```

## 解析与翻译

两项都可选，但提供后复盘时可以逐题查看解析、对照段落翻译。

```json
{
  "translation": [
    { "label": "A", "text": "十年前，在城市里养蜂还被视为一种古怪的爱好……" },
    { "label": "B", "text": "事实证明城市非常适合蜜蜂……" }
  ],
  "explanations": {
    "5": "C 段：蜂箱数量五年翻倍，而开花植物面积 barely changed，所以 TRUE。",
    "6": "D 段 every hive must now be registered，是强制而非自愿，FALSE。"
  }
}
```

- `translation` 与原文段落一一对应：段落有字母时用 `label` 对应，没有字母时按顺序对应。
- `explanations` 的键是题号（字符串），值是这道题的中文解析，可包含定位句和解题思路。

## 图片

- 格式为 PNG 或 JPEG，宽度不低于 1200 像素，放在 `images/` 文件夹。
- 文件名只用英文字母、数字和连字符，建议以套题 id 开头，例如 `c18-test1-p2-diagram.png`。
- 在 JSON 中用相对路径引用：`"image": "images/c18-test1-p2-diagram.png"`。

## 提交前检查

- [ ] 每个 JSON 文件都能通过格式校验（可以用任意 JSON 校验工具检查）。
- [ ] 每篇文章的题号连续、不重复；一整套题共 40 题。
- [ ] 每个题号都有答案；每个 `{{题号}}` 都有对应答案。
- [ ] 每个 `{{题号}}` 在整篇题目中只出现一次（笔记、表格不要逐行累加重复）。
- [ ] 没有 `"undefined"`、`null` 之类的占位文字。
- [ ] 答案中的字母和标题编号都能在对应的 `options` 或 `headings` 中找到。
- [ ] 段落标题匹配题中的 `paragraph` 都在原文 `paragraphs` 中存在。
- [ ] 原文、题目和答案都已和原卷逐字核对。
- [ ] 引用的图片都在 `images/` 中，路径和文件名一致。
- [ ] 所有套题的 `id` 互不重复。

## 完整示例

下面是一篇完整文章（13 题，包含 6 种题型、翻译和解析），可以直接复制，保存为 `sample-test1.json` 作为模板。

```json
{
  "format": "ielts-cd-bank/1",
  "id": "sample-test1",
  "title": "Sample Test 1",
  "module": "academic",
  "source": "格式示例，原创内容",
  "passages": [
    {
      "part": 1,
      "title": "The return of the urban beekeeper",
      "titleZh": "城市养蜂人的回归",
      "frequency": "high",
      "difficulty": 2,
      "text": {
        "heading": "The return of the urban beekeeper",
        "subheading": "Rooftop hives are spreading across the world's cities, but not everyone is convinced they help nature",
        "paragraphs": [
          {
            "label": "A",
            "text": "Ten years ago, keeping bees in a city was regarded as an eccentric pastime. Today there are thousands of hives on the rooftops of London, Paris and New York, many of them installed by restaurants, hotels and office buildings eager to show their **environmental credentials**."
          },
          {
            "label": "B",
            "text": "Cities turn out to suit bees surprisingly well. Parks and private gardens contain a far wider variety of flowering plants than intensively farmed land, and far fewer pesticides are used. Urban areas are also several degrees warmer than the surrounding countryside, which lengthens the foraging season by up to three weeks."
          },
          {
            "label": "C",
            "text": "However, ecologists have begun to raise concerns. Honeybees compete with wild bees for nectar and pollen, and when hives are packed too closely together, wild species can lose out. A study carried out in London in 2019 found that the number of hives had doubled in five years, while the area of flowering plants had barely changed."
          },
          {
            "label": "D",
            "text": "Some city authorities have responded with new rules. In Paris, every hive must now be registered, and several districts limit how many hives may be kept in a single area. New beekeepers are also encouraged to complete a training course before buying their first colony."
          },
          {
            "label": "E",
            "text": "Most experts agree that the answer is not to remove the hives but to increase the food supply. Planting more flowering plants, and linking green spaces through so-called bee corridors, would allow both honeybees and wild pollinators to thrive."
          }
        ]
      },
      "groups": [
        {
          "type": "matching_headings",
          "instruction": "Reading Passage 1 has five paragraphs, A–E. Choose the correct heading for paragraphs B–D from the list of headings below.",
          "headings": {
            "i": "Rules introduced to manage growth",
            "ii": "A hobby that went mainstream",
            "iii": "The financial rewards of honey production",
            "iv": "Advantages of the urban environment",
            "v": "Competition for scarce resources",
            "vi": "Training the next generation of beekeepers"
          },
          "example": { "paragraph": "A", "answer": "ii" },
          "questions": [
            { "number": 1, "paragraph": "B", "answer": "iv" },
            { "number": 2, "paragraph": "C", "answer": "v" },
            { "number": 3, "paragraph": "D", "answer": "i" }
          ]
        },
        {
          "type": "true_false_not_given",
          "instruction": "Do the following statements agree with the information given in Reading Passage 1?",
          "questions": [
            { "number": 4, "text": "Honey produced in cities contains fewer pesticides than honey from the countryside.", "answer": "NOT GIVEN" },
            { "number": 5, "text": "In London, the number of hives grew faster than the area of flowering plants.", "answer": "TRUE" },
            { "number": 6, "text": "Registering a hive in Paris is voluntary.", "answer": "FALSE" }
          ]
        },
        {
          "type": "sentence_completion",
          "wordLimit": "ONE WORD ONLY",
```
